# itunes1-OSX-disassemble

This is a machine-generated disassembly of iTunes version 1.1a1 for Mac OS X 10.0. The PowerPC assembly is just thrown out here because I need help with this.

This code has not been documented or made readable in any way, it is mainly to aid in the production of a full decompilation of iTunes in the near future. However, for all intents and purposes it can be modified.

This was primarily produced by a machine and may contain some errors that can be manually corrected or AI-corrected. It is not fully functional.

Disassembled with Ghidra for Linux.
